# Contributing

Thanks for helping NetGlance. Keep changes local-first, privacy-first, and simple enough for self-hosted users. Do not add telemetry, analytics, hosted tracking, accounts, or external MAC/device lookup APIs.

## Development

1. Copy `.env.example` to `.env`.
2. Use `ENABLE_DEMO_MODE=true` if you do not have NetAlertX available.
3. Run `npm run test`, `npm run typecheck`, and `npm run build` before opening a PR.
